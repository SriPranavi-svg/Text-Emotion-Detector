# 😊 Text Emotion Detector

An AI-powered web application that predicts emotions from text using Python, Streamlit, and a pretrained Hugging Face model.

## 🚀 Live Demo

**[Click here to try the Text Emotion Detector](https://text-emotion-detector-1.streamlit.app/)**

## 🛠️ Technologies Used
- Python
- Streamlit
- Hugging Face Transformers
- PyTorch

## ✨ Features
- Predicts seven emotions: anger, disgust, fear, joy, neutral, sadness, and surprise.
- Displays a confidence score.
- Simple and user-friendly interface.

## ▶️ Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
